# Disaster Relief Resource Coordination System

This repository is organized as a full-stack project with clear separation between application code and project documentation.

## Structure

```text
backend/   Spring Boot backend
fontend/   React + Vite frontend
docs/      Planning, notes, reference, and operational docs
```

## Frontend Docs

Frontend notes and planning files were moved out of the runtime app folder into:

- `docs/frontend/notes`
- `docs/frontend/planning`
- `docs/frontend/reference`
- `docs/frontend/operations`

## Running the Frontend

```bash
cd fontend
npm install
npm run dev
```

## Running the Backend

Run the backend from the `backend/` folder using the project's Java/Spring setup.

# Frontend Docs

This folder holds frontend documentation that does not belong inside the runtime app folder.

- `notes/`: weekly requirements, accessibility audit, and working notes
- `planning/`: planning artifacts, ownership notes, and weekly plan files
- `reference/`: user-flow and integration reference documents
- `operations/`: deployment and environment handoff documentation

The actual frontend application lives in `frontend/`.
